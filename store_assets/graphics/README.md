# Guia de Ativos Gráficos - Play Store

Para uma publicação de sucesso, utilize as especificações abaixo para criar as artes da loja.

## 1. Ícone do App (Icon)
*   **Tamanho:** 512 x 512 px
*   **Formato:** PNG (32 bits, com transparência)
*   **Peso Máximo:** 1 MB
*   **Sugestão Criativa:** Um escudo azul (`#1976D2`) com um ícone de telefone branco no centro, ou um telefone dentro de um círculo verde de "permitido". Deve transmitir segurança e simplicidade.

## 2. Imagem de Capa (Feature Graphic)
*   **Tamanho:** 1024 x 500 px
*   **Formato:** PNG ou JPEG
*   **Sugestão Criativa:** Fundo em degradê azul suave. No lado direito, um mockup de smartphone exibindo a tela principal do app. No lado esquerdo, o texto: "O controle das suas chamadas em suas mãos" em branco. Mantenha os elementos importantes longe das bordas (margem de segurança de 15%).

## 3. Capturas de Tela (Screenshots)
*   **Requisito:** No mínimo 2 capturas (máximo 8).
*   **Formato:** Proporção 16:9 ou 9:16 (mínimo 320px).
*   **Sugestões de Telas:**
    1.  **Tela Principal Ativa:** Mostrando o card de "Proteção Ativa" ligado.
    2.  **Lista Branca:** Exibindo contatos organizados e a barra de busca.
    3.  **Adicionar Número:** Mostrando como é fácil salvar uma nova exceção.

## 4. Banner para Tablets (Opcional mas recomendado)
*   **7 polegadas:** Screenshots de 1920x1080.
*   **10 polegadas:** Screenshots de 2048x1536.

---

> [!TIP]
> Use o site [Canva](https://www.canva.com) ou [Figma](https://www.figma.com) para criar esses ativos rapidamente usando os tamanhos acima. Mantenha o design limpo e moderno, combinando com o estilo Material 3 do aplicativo.
